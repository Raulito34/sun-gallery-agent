# WhatsApp Reply Skill

Sun Gallery WhatsApp 답장을 생성합니다.

## 사용법
사용자가 WhatsApp 메시지 답장을 요청하면 이 스킬이 활성화됩니다.

## 규칙

### 길이 제한
- **3-5문장 이내** 엄격 준수
- 이보다 길어지면 안 됩니다

### 스타일
- 핵심 정보만 포함 (부스 번호, 작가명, 기간 등)
- 이모지 최소화 (1-2개 이내)
- 친근하되 프로페셔널
- 직접 만남 유도 (페어/전시 방문 제안)

### 포함할 정보
- 질문에 대한 직접적인 답변
- 관련 부스 번호나 일정 (해당 시)
- 만남 제안 또는 다음 단계

### 금지 사항
- 장문의 설명
- 과도한 세일즈 언어
- 내부 전략 정보 노출
- 작품을 투자 수단으로 설명
