# Art Translation Skill

Sun Gallery 미술 전문 번역을 수행합니다.

## 사용법
한국어, 영어, 아랍어 간 미술 관련 번역 요청 시 활성화됩니다.

## 지원 언어
- 한국어 (KR) ↔ 영어 (EN)
- 한국어 (KR) ↔ 아랍어 (AR)
- 영어 (EN) ↔ 아랍어 (AR)

## 작가명 표기 규칙
| 한글 | 영문 | 주의 |
|------|------|------|
| 이정지 | Chungji Lee | NOT 이충지, NOT Choongji |
| 곽훈 | Hoon Kwak | |

| 김정수 | Jungsoo Kim | |
| 이영지 | Youngji Lee | |

## 아랍어 표기
- 갤러리명: معرض صن (Ma'rad San)

## 미술 용어 일관성
- 단색화 → Dansaekhwa (NOT monochrome painting)
- 한지 → Hanji (Korean traditional paper)
- 석채 → Stone color pigment
- 팔레트나이프 → Palette knife

## 한국어 공식 문서
- 명사형 종결 사용
- 존칭과 격식 중시
- KAMS 미션 부합 용어
