# Gallery Context Skill

이 스킬은 다른 스킬들이 참조하는 배경 지식을 제공합니다.
사용자가 직접 호출하지 않으며, 다른 스킬 실행 시 자동으로 참조됩니다.

## 컨텍스트 파일
`context/sun_gallery_agent_context_v3.md` 파일에 갤러리의 전체 맥락이 포함되어 있습니다.

## 주요 내용
1. 갤러리 기본 정보 (설립 1977년, 인사동 위치)
2. 소속 작가 로스터 (30명)
3. 아트페어 참가 이력 및 일정
4. 주요 갤러리 전시
5. 비즈니스 정책 (수수료, 가격, 거래 조건)
6. 시장 전략
7. 커뮤니케이션 가이드
8. 고객/파트너 관계 데이터
9. 판매 후 프로세스
10. 물류/배송
11. 현재 진행 프로젝트
12. 위험/주의 사항
13. 내부 전략 (대외 커뮤니케이션에 절대 노출 금지)

## 핵심 원칙
- 섹션 13의 내부 전략 정보는 대외 출력에 절대 포함하지 않음
- AI가 내부적으로 맥락을 이해하고 판단하는 데만 사용
