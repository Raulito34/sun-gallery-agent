# SNS Marketing Skill — Sun Art Center

Sun Art Center(선아트센터) 전용 SNS 마케팅 콘텐츠를 생성합니다.
Instagram과 X(Twitter) 포스팅을 위한 텍스트, 해시태그, 이미지 프롬프트를 만듭니다.

> **브랜드 분리 필수**: "Sun Art Center" / "선아트센터"만 사용. "선화랑" / "Sun Gallery" 절대 사용 금지.

## 사용법

SNS 콘텐츠 요청, 마케팅 캘린더, 포스팅 큐 관련 요청 시 활성화됩니다.

- `/sns` — 마케팅 현황
- `/sns_generate <주제>` — 콘텐츠 즉시 생성
- `/sns_queue` — 큐 확인

## 브랜드 가이드라인

### 톤 & 보이스
- **전문적이면서 따뜻한**: 신진 작가를 응원하는 갤러리의 느낌
- **한국어 + 영어 병기**: 한국어 먼저, 영어 아래 (해외 관객 고려)
- **이모지 적절 사용**: 과하지 않게, 포인트로만
- **CTA(행동 유도) 포함**: "방문하세요", "DM for inquiry" 등


- Instagram: @sunartcenter (생성 예정)
- X: @sunartcenter (생성 예정)
- 위치: 서울 종로구 인사동

### 금지 사항
- "선화랑" / "Sun Gallery" 브랜드 혼용
- 내부 전략, 수수료, 대관료 금액 직접 노출
- "invest in art" 등 투자 언어
- 작가 간 상업성 비교

## 플랫폼별 규격

### Instagram
- **캡션**: 최대 2,200자 (이상적: 800-1,200자)
- **해시태그**: 최대 30개 (이상적: 10-15개)
- **이미지**: 1:1 (1080x1080) 또는 4:5 (1080x1350)
- **Reels**: 9:16 (1080x1920), 15-90초
- **Stories**: 9:16, 24시간 후 사라짐

### X (Twitter)
- **트윗**: 최대 280자
- **이미지**: 16:9 (1200x675) 또는 1:1
- **쓰레드**: 여러 트윗 연결 가능

## 콘텐츠 생성 시 참조할 파일

- `backend/data/sac_pricing.json` — 공간별 면적, 대관료 정보
- `scripts/sac_website_api.py` — SAC 웹사이트에서 실시간 전시/대관 데이터 조회
- `scripts/sns_marketing.py` — 콘텐츠 큐 관리, 포스팅 함수
- `context/sun_gallery_agent_context_v3.md` — 갤러리 배경 지식 (Section 13 제외)

## 이미지 가이드

SNS 콘텐츠에는 이미지가 필수입니다. 3가지 소싱:

1. **SAC 웹사이트**: 전시/공간 사진 (`imageUrl` 필드)
2. **사용자 제공**: Telegram으로 사진 전송 요청
3. **AI 이미지 프롬프트**: 매 콘텐츠에 DALL-E/Midjourney용 영문 프롬프트 1줄 포함

### 이미지 프롬프트 예시
```
Minimalist gallery space with white walls, dramatic natural lighting casting
long shadows, contemporary installation art, architectural photography style,
warm tones, 4:5 aspect ratio
```
